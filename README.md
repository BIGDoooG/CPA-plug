# CPA Codex Plugin Store

CPA `codex-quota-scheduler` 插件的公共安装源。

## 插件源地址

```text
https://raw.githubusercontent.com/BIGDoooG/CPA-plug/main/registry.json
```

CPA 配置示例：

```yaml
plugins:
  enabled: true
  store-sources:
    - "https://raw.githubusercontent.com/BIGDoooG/CPA-plug/main/registry.json"
```

当前发布版本：`0.3.0-canary.3`，平台：`linux/amd64`。
